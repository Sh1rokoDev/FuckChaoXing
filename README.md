# 学习通任务点自动助手（视频 + LLM 自动答题）

适用于超星学习通（chaoxing.com）学习页面的 Tampermonkey 油猴脚本。

自动遍历当前课程课时，完成两类任务点：

- **视频任务点**：自动播放、监控进度、确认完成（服务端 `isPassed` + 页面任务点状态双重判定）；自动探测课程允许的最高倍速并实测生效，不允许时回退 1x
- **答题任务点**：调用**多模态大模型**逐题作答，自动还原**字体混淆**、支持图片题

切换课时/卡片全程 AJAX 或软导航，**不会整页刷新**，悬浮面板与日志不会重建。

> 基于对实际学习通页面的实地 DOM / 网络行为分析实现，非网上脚本移植。
>
> **脚本不会自动提交试卷。** 作答完成后只点击「暂时保存」暂存答案，最终提交必须由你在学习通页面上手动点击。

## 构建

```bash
node build.mjs           # 一次性构建
node build.mjs --watch   # 监听 src/ 变化自动重建
```

改源码后必须运行构建，产物 `chaoxing-video-autoplayer.user.js` 才是最新的。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. Tampermonkey 面板 → 添加新脚本 → 粘贴 `chaoxing-video-autoplayer.user.js` 全部内容并保存
3. 打开任意课程的学习页面（`mooc1.chaoxing.com/mycourse/studentstudy?...`），右上角出现悬浮面板

## 使用

### 1. 高级设置（模型与作答）

点击面板左上角 **⚙** 打开「高级设置」：

**作答设置**

- **题型**：单选题 / 多选题 / 判断题，至少保留一项；未勾选及填空、简答等题型会跳过
- **无答案时**：模型未给出答案时留空或随机选择

**大模型设置**

| 字段 | 说明 |
| --- | --- |
| Base URL | OpenAI 兼容地址，如 `https://api.openai.com/v1`，也可填内网地址 |
| API Key | 仅保存在本地浏览器存储 |
| 模型 | **必须是支持图片输入的多模态模型**，如 `gpt-4o`、`qwen-vl-max`、`glm-4v` 等 |
| 接口风格 | `Chat Completions` 或 `Responses API` |

点「测试连通性」验证后保存。

> 请求通过 `GM_xmlhttpRequest` 发出，可访问内网地址，且不受页面 CSP 与混合内容（https 页面请求 http 接口）限制。
>
> ⚠️ 脚本必须通过 **Tampermonkey 安装并启用**才能正常调用模型接口。若未运行在油猴环境中（`GM_xmlhttpRequest` 不可用），脚本会退化为页面 `fetch`，此时 https 页面无法访问 http 接口（混合内容拦截），脚本会在启动日志中明确提示并快速失败，而不是无意义地反复重试。

### 2. 面板设置

| 项 | 说明 |
| --- | --- |
| 静音播放 | 视频静音播放（观看时长照常上报） |
| 最高倍速 | 自动读取播放器开放的倍速档位并选择最高档；应用后持续校验，被站点重置或提示“不可倍速”时自动回退 1x |
| 自动答题 | 是否处理答题任务点 |
| 自动暂存 | 作答后自动点击「暂时保存」 |
| 跳过已作答 | 已有答案的题目不再作答 |

- **开始刷课**：扫描课程目录 → 从当前课时起逐个处理任务点；按钮随即变为 **停止**
- **高级设置（⚙）**：打开模型与作答设置；模型未配置时按钮右上角显示红点
- **停止**：立即终止定时器 / 监听 / 流程，不再自动切课
- **拖动**：按住面板背景、状态卡或设置区标题等非交互区域拖动面板（日志区保留文字选择与滚动）；点击右上角 **⌃** 收起为圆形播放按钮，点击圆形按钮或拖动它可重新展开/移动
- 运行状态会被记忆：刷新或重新进入学习页后自动续跑，点「停止」即取消

### 3. 日志卡片

右侧「运行日志」按**卡片**组织，一张卡片对应一个课时（或一道题）；日志头右侧显示当前课时进度（`序号 / 总数  课时名`）：

| 卡片 | 内容 |
| --- | --- |
| 系统信息 | 脚本加载、配置状态、环境自检、课程扫描与导航方式 |
| 视频任务 / 课时任务 | 每个课时一张：进入课时 → 任务点处理（播放进度、倍速、暂停恢复、完成判定）→ 课时结束 |
| 单道题目 | 每题一张：题目图缩略图 → 模型回答与依据 → 点选结果 |

题目卡片的缩略图**点击后以弹窗展示原图**（不再在日志内放大），便于核对发送给模型的截图。日志只保留最近 220 张卡片，超出后淘汰最早的卡片。

### 4. 答题后手动提交

```
[WARN] ⚠ 请在学习通页面上人工复核答案后，手动点击「提交」完成任务点
```

答案已点选并暂存到服务器，进页面确认无误后点「提交」即可。

## 处理规则

| 任务点类型 | 行为 |
| --- | --- |
| 视频任务点（未完成） | 自动播放 → 探测并开启最高可用倍速 → 监控 → 确认完成后进入下一个 |
| 视频任务点（已完成） | 跳过 |
| 答题任务点（未完成） | 逐题截图 → 多模态模型作答 → 自动点选 → 暂时保存 |
| 答题任务点（已完成） | 跳过 |
| 非选择题型（填空/简答/连线…） | 跳过（仅支持单选 / 多选 / 判断） |
| 其他任务点 | 跳过 |

## 倍速自动探测与校验

不少课程虽然显示了倍速菜单，但学校/教师实际禁止未完成任务点倍速播放。脚本不假设“有菜单就能用”，而是：

1. 从 VideoJS 播放器配置 `playbackRates` 与倍速菜单中读取课程真实开放的档位；
2. 从最高档开始应用（直接触发播放器自己的倍速菜单项，走官方切换逻辑）；
3. **持续观察 2.6 秒**：`playbackRate` 被重置，或播放器出现包含“倍速”的限制提示，即判定该档不可用；
4. 逐档降低重试，全部不可用则**回退 1x**，并在视频卡片记录原因；
5. 播放暂停恢复、媒体源重载后自动重新应用；若播放中倍速被反复重置（60 秒内 2 次），判定为站点限制并停止尝试。

可在面板「运行设置 → 最高倍速」中关闭该行为。

## 无刷新切课

- 课时切换优先调用页面自带的 `getTeacherAjax`（AJAX 替换 `#mainid`，不刷新页面）；
- 该函数缺失或超时时，复用站点 `studentstudyAjax` 接口填充 `#mainid`（保留卡片标签等页面状态）；接口也不可用才直接切换内容 iframe；
- **导航方式一次选定后缓存复用**：仅在首次确定或方式变更时记录一条日志，不会每个课时都输出回退提示；
- 直切 iframe 前会用 `studentstudyAjax` 返回的 HTML 同步顶部卡片标签，保证多卡片课时不漏处理；
- **任何路径都不再使用 `location.href` 整页跳转**；
- 脚本运行期间临时关闭站点自身的“自动连播”（`videoAutoPlay`），避免站点自动跳节与脚本切课竞争；
- 任务点完成后先暂停视频并等待约 1.2 秒，让最后一次进度上报收尾，再切换课时，避免请求被中途掐断导致站点刷新；
- 「停止」时同样会暂停当前视频并恢复站点自动连播设置。

## 字体混淆的处理（核心机制）

学习通对题干与选项使用了**动态字体映射混淆**：

- 页面注入 `@font-face { font-family: font-cxsecret; src: url("data:...base64...") }`
- 字体文件仅约 12KB、36 个字形，**每次页面加载随机生成映射**
- 同一段密文（如 `壋于`）在不同页面加载时渲染出的真实文字不同
- 纯文本抓取只能得到乱码（DOM 里存的确实就是 `壋于`）

### 渲染流程

```
题目 DOM
  └─ 克隆 + 逐节点内联 getComputedStyle（字体族/字号/字重/颜色）
  └─ 题干与选项内的 <img> 转 dataURL 内联（避免污染画布 / 绕过混合内容）
  └─ 把 @font-face（data: URL）直接嵌进 SVG 的 <style>
       └─ <svg><foreignObject>…</foreignObject></svg>
            └─ data:image/svg+xml → Image → canvas → PNG
```

**首选路径是 SVG `foreignObject` 原生栅格化**：使用浏览器自己的排版引擎，
换行、公式、表格与页面完全一致；字体以 data URL 直接内嵌，不依赖任何字体注册流程。

若原生栅格化失败，回退到 canvas 逐行重绘（此时混淆字体会先注册到顶层文档）。

### 渲染正确性自检（重要）

渲染后强制自检，**防止把混淆后的密文当成题目发给模型**：

1. 解析字体二进制的 `cmap`，得到该字体覆盖的码点集合 —— 这些码点就是被替换掉的字符
2. 取题目文本中命中该集合的字符作为探针
3. 用**与正式渲染完全相同**的管线渲染探针，再与系统字体渲染结果比较位图
   - 两者有显著差异 → 字体生效，渲染可信
   - 两者完全一致 → 字体未生效，**拒绝发送该图片**，记录 ERROR 并跳过该题

> 宁可跳过不作答，也不把密文喂给模型导致静默错答。

### 踩坑记录

早期版本用 `document.fonts.check()` 判断「字体是否已注册」：

```js
if (document.fonts.check('16px "font-cxsecret"')) return true;   // ✗ 错误
```

该方法的语义是「字体列表中是否没有待加载的字体」，**对完全未注册的字体族同样返回 `true`**，
导致注册被静默跳过，canvas 找不到字体而回退系统字体，把密文原样画了出来。
现改为按字体数据指纹记录注册状态，并在映射变化时删除旧同族 `FontFace` 后重新注册。

## 异常处理

- 单任务点失败：重试 2 次 → 仍失败记 ERROR → 跳过，继续后续任务点
- 单题渲染失败或自检不通过：记录 ERROR 并跳过该题（不中断其余题目）
- 模型未返回答案：默认**留空不作答**（可在配置中改为随机选择）
- **环境类问题快速失败**：未在油猴环境中运行、接口地址不可达等不可恢复的错误，会立即中止并给出可执行提示（不做无意义重试）
- 页面 / iframe 加载慢：基于状态检测轮询等待（含超时），不用固定延时猜测
- 课时切换：AJAX / 软导航双通道，**任何情况下都不整页刷新**（详见上文「无刷新切课」）
- 停止机制：统一停止信号（Symbol）贯穿所有 `sleep/waitFor`，停止时立即拒绝挂起等待、断开全部 MutationObserver、暂停当前视频、恢复站点连播设置、清理定时器
- 正常跑完全部课时会清除续跑标记，避免下次打开学习页又自动开始；只有异常中断/手动刷新时才保留标记以便续跑

## 已知边界

- **不自动提交试卷**（设计如此，避免误提交）
- **仅支持单选题 / 多选题 / 判断题**，其余题型跳过
- 视频内弹题不自动作答：脚本会识别弹题并暂停进度判定、等待手动作答（最长 5 分钟），不会误判为网络卡顿
- 验证码、人脸识别等环节脚本不处理
- 未处理考试、直播等特殊页面
